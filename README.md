# 🏃 Sanaa Runner | صنعاء رنر

A 3D Endless Runner game inspired by the beautiful city of **Sanaa, Yemen**.

## 🎮 Play Now

**[Play Sanaa Runner](https://sanaa-777.github.io/sanaa-runner/)**

## ✨ Features

- 🎭 **3D Yemeni Character** (Thobe, Vest, Shmagh, Sneakers)
- 🏛️ **Sanaa City Environment** with traditional architecture
- 🏃 **Endless Runner Gameplay** with 3 lanes
- 💰 **Coins & Power-ups** (Magnet & Shield)
- 📱 **Mobile Optimized** with touch controls
- 💾 **Save System** with local storage
- 🎨 **Professional UI** with HUD, Pause, Game Over screens

## 🕹️ Controls

| Action | Mobile | Keyboard |
|--------|--------|----------|
| Switch Lanes | Swipe ← → | A/D or ← → |
| Jump | Swipe ↑ | W or ↑ or Space |
| Slide | Swipe ↓ | S or ↓ |
| Pause | - | P or Esc |

## 🛠️ Tech Stack

- Three.js (3D Engine)
- HTML5 Canvas
- Vanilla JavaScript
- CSS3

## 📱 Install as App

1. Open the game in Chrome/Safari
2. Tap "Add to Home Screen"
3. Play offline anytime!
