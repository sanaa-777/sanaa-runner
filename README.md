## ✨ What's New in v2.0 Pro

### 🎵 Audio Engine
- Web Audio API synthesized sounds
- Coin chimes, jump whoosh, crash impact
- Power-up activation sounds
- Lane switch feedback

### 📳 Haptic Feedback
- Vibration on coin collect, jump, crash
- Pattern-based feedback for power-ups

### 🔥 Combo System
- Chain coin collections for multiplier
- x2, x3, x4 score multipliers
- Combo timer with visual indicator

### 🎬 Professional Animations
- Smooth lane switching with easing
- Character lean on turns
- Landing squash & stretch
- Breathing animation in menu
- Dust trail behind runner

### 📷 Dynamic Camera
- FOV scales with speed
- Screen shake on impact
- Smooth follow with lag
- Tilt on turns

### ⚡ Performance
- Auto low-quality mode on weak devices
- Object pooling
- Frustum culling
- Fog optimization

## 🕹️ Controls

| Action | Mobile | Keyboard |
|--------|--------|----------|
| Switch Lanes | Swipe ← → | A/D or Arrow Keys |
| Jump | Swipe ↑ | W, ↑, or Space |
| Slide | Swipe ↓ | S or ↓ |
| Pause | - | P or Esc |

## 🏛️ Features

- 🎭 **3D Yemeni Character** with Thobe, Vest, Shmagh, Sneakers
- 🏛️ **Sanaa City** with traditional architecture & Qamariya windows
- 💰 **Coins** with arc patterns & magnet effect
- 🛡️ **Power-ups**: Magnet + Shield
- 🎯 **Combo System** for score multipliers
- 📊 **Save System** with localStorage
- 📱 **PWA** - Install as app on home screen
- 🌍 **Responsive** - Works on all devices

## 🛠️ Tech Stack

- Three.js r128
- Web Audio API
- Vibration API
- HTML5 Canvas
- CSS3 Animations
- localStorage
